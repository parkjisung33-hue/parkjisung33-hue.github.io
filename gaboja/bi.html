동우님 레퍼런스로 만든 로고 4안이에요. 위의 색 · 글꼴을 바꾸면 로고·앱 아이콘·첫 화면·탑승권이 한꺼번에 바뀌어요(브랜드 토큰). 마음에 드는 조합을 고르고 맨 아래 답 복사로 보내 주세요.

레퍼런스에서 가져온 것
  • 바다·하늘 사진 + 사전 표기(‘sea /sē/ noun’) → 첫 화면 문법, D안
  • 글자 하나가 길·비행기·가방이 되는 워드마크(TRAVEL·TOUR·fly) → A·B·C안
  • ‘조용한 색 둘 + 시끄러운 색 하나’, ‘차가운 바탕엔 따뜻한 강조’ → 색 3벌
  • 친근 / 스위스 / 개성 글꼴 → 무료 글꼴로 대신(아래 메모)

참고

• 레퍼런스의 유료 글꼴(Circular·GT Walsheim·ABC Diatype·Obviously 등)은 사서 써야 해서, 비슷한 무료 글꼴로 대신했어요. 친근 = Figtree(Circular 계열), 스위스 = Inter Tight, 개성 = Unbounded. 한글은 지금처럼 Pretendard.
• 첫 화면 바다는 사진 대신 그린 그림이에요. 실제 사진은 브랜드 정한 뒤 무료 사진으로 바꿔요.
• A·B·C 로고는 선 하나 굵기(둥근 끝)로 그려서, 글꼴을 바꿔도 로고 모양은 그대로예요. D만 글꼴 따라 바뀌어요.
• 레퍼런스 중 ‘타이포 규칙’은 화면 다듬을 때, ‘출시 전 점검 20가지’는 서버 단계(E0) 때 쓸게요.
